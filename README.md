# StudyMind ENEM

## Sobre o projeto

O StudyMind ENEM é um protótipo de assistente de estudos
personalizado desenvolvido utilizando o Google NotebookLM.

O projeto busca utilizar Inteligência Artificial e Engenharia
de Prompts para ajudar estudantes a identificar dificuldades,
priorizar conteúdos e organizar seus estudos para o ENEM.

## Objetivo

Criar um fluxo de estudos capaz de:

- analisar dificuldades do estudante;
- identificar conteúdos prioritários;
- criar sessões de estudo;
- gerar exercícios;
- analisar erros;
- recomendar revisões;
- reavaliar o desempenho.

## Como funciona

O StudyMind utiliza o seguinte ciclo:

Diagnóstico
↓
Planejamento
↓
Estudo
↓
Teste
↓
Análise dos erros
↓
Revisão
↓
Reavaliação

## Fontes utilizadas

O projeto utiliza fontes relacionadas ao ENEM, incluindo:

- Matriz de Referência do ENEM;
- Cartilha do Participante – Redação;
- provas anteriores do ENEM;
- gabaritos oficiais;
- materiais educacionais oficiais;
- perfil e desempenho do estudante.

## Engenharia de Prompts

Foi desenvolvida uma cadeia de prompts para:

1. análise geral do ENEM;
2. mapeamento de conteúdos;
3. análise de desempenho;
4. identificação de lacunas;
5. priorização;
6. planejamento;
7. revisão;
8. testes personalizados;
9. análise dos erros;
10. reavaliação.

## Testes realizados

O protótipo foi testado em situações como:

- identificação de prioridades;
- criação de sessões de estudo;
- análise de redação;
- utilização de repertório;
- análise de erros;
- adaptação das recomendações.

## Limitações encontradas

Durante os testes, foi observado que a IA pode ocasionalmente
tirar conclusões fortes a partir de poucas evidências.

Por exemplo, uma única resposta correta não deve ser considerada
prova suficiente de domínio de determinado conteúdo.

Por isso, o sistema utiliza reavaliações e novos testes para
confirmar a evolução do estudante.

## Resultado

O resultado foi um protótipo capaz de orientar um ciclo de estudos
personalizado utilizando informações do estudante e fontes
selecionadas sobre o ENEM.
