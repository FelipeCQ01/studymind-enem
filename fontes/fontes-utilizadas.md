# Fontes Utilizadas — StudyMind ENEM

A curadoria de fontes foi uma etapa importante do desenvolvimento do **StudyMind ENEM**, pois as análises realizadas pelo Google NotebookLM são fundamentadas nos materiais adicionados ao notebook.

Foram priorizadas fontes oficiais relacionadas ao ENEM, provas anteriores, materiais educacionais e documentos próprios do projeto.

---

## 1. Matriz de Referência do ENEM

**Origem:** INEP

### Finalidade no projeto

A Matriz de Referência foi utilizada como base para compreender:

* competências;
* habilidades;
* eixos cognitivos;
* organização das áreas avaliadas pelo ENEM.

Essa fonte ajudou o StudyMind a relacionar conteúdos estudados às habilidades exigidas pelo exame.

---

## 2. Cartilhas do Participante — Redação

**Origem:** INEP

Foram utilizadas cartilhas oficiais de Redação do ENEM disponíveis durante o desenvolvimento do projeto.

### Finalidade no projeto

As cartilhas serviram como referência para:

* compreender as cinco competências da Redação;
* analisar critérios de avaliação;
* trabalhar argumentação;
* projeto de texto;
* repertório sociocultural;
* coesão;
* proposta de intervenção.

Essa fonte foi especialmente importante porque a Redação apareceu como uma das principais dificuldades identificadas durante os testes do StudyMind.

---

## 3. Provas anteriores do ENEM

Foram adicionadas provas dos anos:

* ENEM 2023;
* ENEM 2024;
* ENEM 2025.

Foram considerados materiais referentes aos diferentes dias de aplicação disponíveis para análise.

### Finalidade no projeto

As provas anteriores permitiram observar:

* características das questões;
* conteúdos abordados;
* competências e habilidades relacionadas;
* exemplos reais do exame;
* diferentes formas de contextualização dos conteúdos.

Essas provas também serviram como referência para atividades e diagnósticos realizados pelo sistema.

---

## 4. Gabaritos oficiais

Foram utilizados gabaritos correspondentes às provas analisadas de:

* 2023;
* 2024;
* 2025.

### Finalidade no projeto

Os gabaritos permitiram conferir respostas das questões oficiais e apoiar atividades de diagnóstico e análise de desempenho.

---

## 5. Materiais educacionais oficiais do INEP

Também foram adicionados materiais educacionais oficiais relacionados às quatro grandes áreas:

* Matemática e suas Tecnologias;
* Ciências da Natureza e suas Tecnologias;
* Ciências Humanas e suas Tecnologias;
* Linguagens, Códigos e suas Tecnologias.

### Finalidade no projeto

Esses materiais foram utilizados como apoio para:

* explicações de conteúdos;
* organização conceitual;
* revisão;
* criação de atividades;
* identificação de relações entre conteúdos e áreas.

---

# Fontes próprias do StudyMind

Além das fontes externas, foram criados documentos específicos para fornecer ao NotebookLM informações sobre o funcionamento do protótipo e sobre o estudante.

---

## 6. Perfil e Desempenho do Estudante — StudyMind ENEM

Documento criado para reunir informações sobre o estudante.

Entre os dados utilizados estavam:

* desempenho registrado por área;
* principais dificuldades;
* percepção do estudante sobre seu próprio domínio;
* desempenho em Redação;
* tempo disponível para estudo;
* histórico de avaliações disponível.

### Finalidade no projeto

Essa fonte permitiu que o StudyMind comparasse:

**O que o ENEM exige**

com

**A situação atual do estudante**

Essa comparação é uma das bases da personalização proposta pelo projeto.

---

## 7. Critérios de Priorização — StudyMind ENEM

Documento criado para estabelecer uma lógica de priorização dos conteúdos.

### Finalidade no projeto

A fonte foi utilizada para orientar classificações como:

* **MUITO ALTA**
* **ALTA**
* **MÉDIA**
* **BAIXA**

A priorização considera fatores como relevância para o ENEM, desempenho do estudante, dificuldades identificadas e evidências disponíveis.

---

## 8. Manual Operacional — StudyMind ENEM

Documento criado durante o desenvolvimento do protótipo para organizar sua metodologia de funcionamento.

### Finalidade no projeto

O manual descreve a lógica dos módulos e o ciclo de aprendizagem utilizado pelo StudyMind:

**DIAGNÓSTICO → PLANEJAMENTO → ESTUDO → TESTE → ANÁLISE DOS ERROS → REVISÃO → NOVO TESTE → NOVO DIAGNÓSTICO**

Também estabelece princípios importantes, como:

* utilizar evidências antes de determinar uma dificuldade;
* evitar inventar informações sobre o estudante;
* justificar recomendações;
* atualizar prioridades conforme surgem novos resultados.

---

# Critério de Curadoria

A seleção das fontes buscou combinar três tipos de informação:

### 1. O que o ENEM exige

Representado principalmente por:

* Matriz de Referência;
* Cartilhas de Redação;
* provas anteriores;
* gabaritos oficiais.

### 2. Material para estudo e compreensão

Representado pelos materiais educacionais adicionados ao NotebookLM.

### 3. Situação individual do estudante

Representada pelos documentos próprios do StudyMind, principalmente:

* Perfil e Desempenho do Estudante;
* Critérios de Priorização;
* Manual Operacional.

---

# Papel das fontes no StudyMind

A lógica central do projeto pode ser resumida como:

**FONTES DO ENEM + MATERIAIS DE ESTUDO + DADOS DO ESTUDANTE**

↓

**ANÁLISE COM NOTEBOOKLM**

↓

**IDENTIFICAÇÃO DE LACUNAS**

↓

**PRIORIZAÇÃO**

↓

**PLANO DE ESTUDOS PERSONALIZADO**

↓

**TESTES E ANÁLISE DE ERROS**

↓

**REAVALIAÇÃO**

Dessa forma, o StudyMind ENEM não foi desenvolvido apenas para responder perguntas sobre o ENEM, mas para utilizar diferentes fontes como contexto para produzir recomendações de estudo mais direcionadas.
